# SankofaVR

SankofaVR is a cultural identity VR experience designed to reconnect the African diaspora with the diverse heritage of Africa. The project uses the web-based [A-Frame](https://aframe.io) framework to deliver immersive storytelling directly in the browser.

This demo includes a simple scene with 3D objects and text to welcome the user. To try it locally, open `index.html` in a WebVR-compatible browser.

## Goals
- Create immersive environments that showcase Africa's rich history and traditions
- Provide authentic narratives that resonate with the diaspora
- Encourage exploration, learning, and cultural pride through VR
